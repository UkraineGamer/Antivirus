# Antivirus

## Visual scanner (GUI)

A desktop visual app with:
- folder picker
- live loading/progress bar during scan
- threat table (`SAFE` / `WARNING` / `DANGER`)
- click (or right-click) on `WARNING` / `DANGER` rows to choose action:
  quarantine, delete, open location, or ignore
- duplicate groups view
- largest files table

Run:

```bash
python3 antivirus_visual.py
```
